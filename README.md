# 図上演習ノート — 条文で読む、ドイツ 1919–1945

https://soy-tuber.github.io/zujoenshu/

**1ページです。** ヴァイマル憲法48条からニュルンベルク憲章まで、第二次世界大戦に
まつわる公的文書を、条文そのまま——原文と訳を並べて——年代順に読みます。
最後に、これらの文書が実際にどう問われたかを、京都大学と東京大学の入試問題で確かめます。

読む順序は **年表 → 文書 → 過去問**。

## 方針

**なるべく公的資料に当たって、実証的に歴史を見る。**
教科書は条約を一行で要約しますが、要約の段階で落ちるものの中に、この時代の急所が
入っています。だから条文を置きます。

**素材と読みを分ける。** 条文と問題文はそのまま読める場所に置き、本教材の読み
（読みどころ・出題趣旨・ヒント）は「関門」の内側に畳んであります。**自分で骨を
立ててから開く**構成です。

**詰めていない点は隠さない。** 各文書に「未確認の項目」欄があり、この教材が自分で
分かっている宿題を出しています。

## 権利について

- **条文は公表された公的文書**です。憲法・法律・条約・協定・憲章はいずれも保護期間が
  満了しており、条文それ自体は著作権法13条（法令等）の趣旨に照らしても権利の目的と
  なりません。底本の所在（URL・取得日）を各文書に明記しています。
- **訳文はことわりのない限り本教材訳**です。原文を併記してあるので、訳し方まで
  検証できます。
- **入試問題の著作権は各大学に帰属します。** 設問文は出所を明示して引用し、
  大学の公式過去問ページへのリンクを添えています。問題冊子に他者の訳による史料が
  含まれる大問は、このページでは扱っていません。
- 読みどころ・出題趣旨・ヒントは**本教材の読み**であり、出題した大学の公式見解では
  ありません。

誤り・権利上の懸念のご指摘は Issues へお願いします。
