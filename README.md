# 図上演習ノート — 公開版

国立大学（東京大学・京都大学・一橋大学・千葉大学）の世界史・地理の入試問題を、
**出題の趣旨・段階ヒント・答えの骨**とともに読むための静的サイトです。
あわせて、歴史を動かした**条約・規約・布告の条文そのもの**を原文と訳で並べています。

https://soy-tuber.github.io/zujoenshu/

## 方針

**なるべく公的資料に当たって、実証的に歴史を見る。**
教科書は条約を一行で要約しますが、要約の段階で落ちるものの中に、
設問が問うている論点が入っていることがよくあります。だから条文を全文置きます。

**素材と読みを分ける。**
問題文と条文は、そのまま読める場所に置きます。
本教材の読み（出題趣旨・ヒント・読みどころ）は「関門」の内側に畳んであり、
**自分で骨を立ててから開く**構成にしています。先に解説を読むと、
その筋がそのまま自分の筋になり、設問が要求している作業が起きないためです。

**詰めていない点は隠さない。**
条文ページには「未確認の項目」欄があり、この教材が自分で分かっている宿題を出しています。

## 権利について

- **入試問題の著作権は各大学および原著作者に帰属します。** 設問文は出所を明示して
  引用しており、各ページ下部に大学の公式過去問ページへのリンクがあります。
- **問題冊子に載っている「他者の訳による引用史料」は掲載していません。**
  訳文には訳者の著作権が別に生じるためです。該当箇所にはその旨を表示し、
  公式PDFへ案内しています。
- **条約・規約・布告の条文は、公表された公的文書**です。保護期間は満了しており、
  条文それ自体は著作権法13条（法令等）の趣旨に照らしても権利の目的となりません。
  だれでも全文を確かめられます。底本の所在（URL・取得日）を各ページに明記しています。
- **出題趣旨・ヒント・答えの骨・体系・条文の訳文は、本教材の著作物**です。
  ことわりのない訳はすべて本教材訳で、原文を併記してあるので訳し方まで検証できます。
- 出題趣旨は**本教材の読み**であり、出題した大学の公式見解ではありません。
  公式の出題意図が公表されている場合は、そのことを明記して区別しています。

誤り・権利上の懸念のご指摘は Issues へお願いします。
