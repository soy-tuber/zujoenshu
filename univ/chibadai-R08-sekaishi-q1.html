ペルシアは、いつもローマの東側にいた

問題文問題冊子 2ページ〜3ページ

1　次の文章は、古代西アジアとその西方地域との関係についてのものである。これを読んで、以下の設問に答えなさい。

前6世紀半ばにキュロス2世がおこしたAは、またたく間に全オリエントを統一した。①ダレイオス1世のときにギリシア全土の服属を企てるも、これは失敗に終わり、その子クセルクセス1世も同様の遠征をおこなったが、父と同じ轍を踏んだ。この王朝が滅びたのは前330年のことで、②前4世紀半ばにギリシアの覇権を握ったマケドニアは、Bの後を継いだアレクサンドロスのときに東方遠征に乗り出し、当時の王であったダレイオス3世を破って東西にまたがる大帝国を成立させた。

このマケドニアの帝国が崩壊すると、西アジアの領土はセレウコス朝シリアに引き継がれたが、この王朝の弱体化に伴い、ギリシア人によるバクトリアやイラン系遊牧民によるアルサケス朝パルティアといった国々がおこった。③パルティアは地中海圏を支配していたローマに圧力をかけ、前53年には、オロデス2世のもと、カルラエの戦いでローマ軍を撃破した。

パルティアを倒しておこったササン朝ペルシアもローマとしのぎを削り、④3世紀半ばには、第2代皇帝のCが、シリアに侵入したローマ軍を破って、皇帝ウァレリアヌスを捕虜とした。この王朝の最盛期は531年に即位したホスロー1世の時代とされ、彼は、「大帝」と呼ばれた東ローマ皇帝Dと激しく争った。その後、ササン朝ペルシアは、642年のEにおいてアラブ＝ムスリム軍に敗北し、実質的に瓦解した。

  1. 問1文中のA、B、C、D、Eに当てはまる適切な名称を答えなさい。
  2. 問2下線部①の遠征の原因として、ある地方で生じた出来事が挙げられる。その出来事を、その地方の名称を含め、25字以内で説明しなさい。
  3. 問3下線部③のパルティアについて、次の問いに答えなさい。
    1. (1)この国は、中国と最初に交渉を持った西アジアの国としても知られ、前漢時代の歴史家である司馬遷が記した『史記』でも言及がみられる。この作品におけるパルティアに対する呼称を答えなさい。
    2. (2)この国の文化的特徴とその変化について、下線部②の出来事を参考に、125字以内で説明しなさい。
  4. 問4下線部③がきっかけとなり、ローマでは第1回三頭政治が崩壊した。この時の三頭政治に参加した3人の政治家の名前を答えなさい。
  5. 問5下線部④の時期のローマ帝国について、前後の時代状況も含め、次の語句を用いて200字以内で説明しなさい。なお、語句を用いる順番は問わないが、それぞれ最初に用いた箇所に下線を付すこと。
    四帝統治体制　軍人皇帝　ゲルマン人　トラヤヌス
読み物を開く——その前に、設問文だけで骨の見出しを3つ書く

ここから下は本教材の読みです。先に読むと、その筋がそのまま自分の筋になります——答案は語句をつなぐだけの平板なものになり、設問が要求している「自分で核を名指しする」作業が起きません。骨が立たなくてもかまわないので、立てようとしてから開いてください。

アケメネス朝からササン朝まで、千二百年ぶんを一本の文章で通す。西アジアの帝国は入れ替わるのに、「西の地中海世界と押し合う」という役回りだけは変わらない——その反復が主題です。

趣旨 何を問う問題か

▶ 公式の出題意図
公式の出題意図
「本問は、イランを中心とした古代西アジアにおける諸国家の勃興の歴史、および、その西方世界であるギリシア・ローマとの相互の影響関係に関する理解を問う。」——千葉大学「令和8年度入学者選抜学力検査問題 世界史 出題意図」より引用
▶ ここからは本教材の読み
指定語句の使い方（重要）
指定語句は、ヒントではなく答え合わせです。正しい順序は①設問文だけで方向を立てる → ②語句で検算する → ③配置して書く。
語句を先に見て方向を決めると、答案は語句をつなぐだけの平板なものになります。そして本番では——語句を見ないと方向すら思いつかない状態なら、その時点で勝負がついている。だからこの教材では、ヒント1で語句を伏せます。
問5の設問文は「下線部④の時期のローマ帝国について、前後の時代状況も含め」と書いています。下線部④は3世紀半ば——つまりその前と後を書け、と言っている。語句を見なくても「最盛期 → 3世紀の混乱 → 収拾」という山なりの形は出せる。そのうえで語句を開くと、4語がちょうどその順に並んでいることが確かめられます。
問題の骨
公式が言う「相互の影響関係」が鍵です。問3(2)はギリシア文化が東へ入り、やがてイランの伝統が押し返すという往復を書かせる。問5はローマが東（ササン朝）と北（ゲルマン人）から同時に押される話。一方通行の征服史ではないところに、この大問の設計があります。
つまずく所
問3(2)で「ギリシア化した」で止めること。設問は「文化的特徴とその変化」と書いている——変化、つまりあとで戻ったことまで書かないと半分です。
満点への一手
問5は指定語句の順番が、そのまま時代順になっています。トラヤヌス（最盛期）→ 軍人皇帝（3世紀の危機）→ ゲルマン人（外圧）→ 四帝統治体制（収拾）。語句を時系列に並べ替えるだけで骨組みができる。
中学生の目で見るなら
問1と問4は名前を答えるだけ。アケメネス朝ペルシア、アレクサンドロス、ローマの三頭政治は中学の教科書にも出ます。まずそこだけ拾えれば十分——長い論述は高校で戻ってくればいい。

ヒント 詰まったら、上から順に開く

ヒント1 ― 空欄の手がかり
A：前6世紀半ば、キュロス2世、全オリエント統一。
B：アレクサンドロスの父。カイロネイアの戦いでギリシアを制した人。
C：ササン朝第2代。ローマ皇帝ウァレリアヌスを捕虜にした。
D：531年即位のホスロー1世と争った東ローマ皇帝。「大帝」。
E：642年、アラブ＝ムスリム軍にササン朝が敗れた戦い。
ヒント2 ― 語句を伏せて、二つの論述の方向を立てる
問3(2)　設問文は「この国の文化的特徴とその変化について、下線部②の出来事を参考に」。
・「変化」と書いてある → 一つの状態を述べて終わってはいけない。前と後が要る。
・「下線部②を参考に」＝アレクサンドロスの東方遠征 → 外から来たものが先。
→ 骨は①外から入った → ②やがて元が戻ったの二段。ここまで語句は要りません。

問5　設問文は「下線部④の時期のローマ帝国について、前後の時代状況も含め」。
・下線部④は3世紀半ば（ウァレリアヌスが捕虜になった事件）。
・「前後も含め」＝その前は何だったか、その後どうなったかを書け、ということ。
→ 骨は①前＝最盛期 → ②中＝3世紀の混乱 → ③外圧 → ④後＝立て直しの四段。

問3(2)　①ギリシア文化が入った → ②イランの伝統が戻った
問5　　①最盛期 → ②内側の混乱 → ③外からの圧力 → ④体制の作り直しこの形が語句なしで出せるかどうかが、この大問の分かれ目です。
ヒント3 ― 語句を開いて、答え合わせをする（問5）
問5の4語を、いま立てた四段に置いてみる。

トラヤヌス→①前（五賢帝の一人。帝国の最大領域）／軍人皇帝→②中（3世紀、皇帝が乱立した時代）／ゲルマン人→③外圧（侵入。ササン朝の攻勢と重なる）／四帝統治体制→④後（ディオクレティアヌスによる収拾）。
→ 4語が四段に一つずつ、しかも時代順に並びました。骨は合っています。千葉大はこの大問で語句を時系列に並べて配ってきました。逆に言えば、時系列の骨さえ立てば語句は自動的にはまる——だから語句は先に見なくてよかった。

検算の読み方
・置けない語句がある → 方向がずれている合図。骨を組み直す。
・語句が置かれない見出しがある → その論点を自分で補う必要がある（語句は骨の全部を指してはくれない）。

中身の補い　骨に置くだけでは200字になりません。各段に一つずつ理由を足す。
②に帝国財政の逼迫、③にササン朝ペルシアの攻勢（下線部④そのもの）、④に2人の正帝と2人の副帝で分担したという中身。これが「語句が置かれない見出しを自分で補う」ということです。
答えの骨（公式の解答例より）

問2 「イオニア地方で生じた反乱をアテネが支援した。」

問3(1) 安息　(2) 「アレクサンドロスの東方遠征と、それに続くギリシア人の入植をきっかけに、ギリシア文化が西アジア周辺に広く浸透した。これを背景に、パルティアでは当初ギリシア語の文化が重んじられたが、のちにイランの伝統文化が復興し、イラン系の言語が重視された。」

問4 カエサル・ポンペイウス・クラッスス

問5 「ローマ帝国は五賢帝の時代に最盛期を迎え、トラヤヌス帝の時には最大領域に達した。その後、3世紀には短期間に多数の皇帝が乱立してあい争う軍人皇帝の時代となるが、帝国財政が逼迫し、ゲルマン人が帝国に侵入したり、ササン朝ペルシアが攻勢を強めたことも重なって、帝国は分裂の危機に陥った。この混乱を収めるために、ディオクレティアヌス帝は帝国を四分し、2人の正帝と2人の副帝で分担して治める四帝統治体制を敷いた。」公式の解答例が公表されています。ここに示したのはその要点で、千葉大学が公表した「解答例」に基づいています（引用元：令和8年度入学者選抜学力検査問題 世界史 解答例）。それ以外の説明は本教材の読みです。
◎ 理系の補助線

なぜ同じ場所で、同じ形の対立が千二百年もくり返されるのか。アケメネス朝もパルティアもササン朝も、支配の中心はイラン高原で、西の境界はだいたいユーフラテス川からアナトリア東部。ローマ側もギリシア以来ずっと同じ線で止まっている。人が入れ替わっても、境界だけ動かない。

理由は地形と水にあります。イラン高原は標高1000 m以上の乾燥した台地で、外から攻め入る側は補給線が伸びきる。逆に高原側から西へ出れば、メソポタミアの灌漑された豊かな平野がある——取りに行く価値があるのは常に西で、守りやすいのは常に東。この非対称が、押し合いの場所を固定した。

そしてこの押し合いは、東西の交易路の値段を決めていました。中国からの絹は必ずこの緩衝地帯を通る。だからローマは高い関税を払わされ、金銀が東へ流出した——大プリニウスは「インドと中国とアラビアが毎年1億セステルティウスを帝国から吸い上げる」と嘆いています。問3(1)の「安息」（パルティアの中国名）が『史記』に載っているのは、その通商路の逆側からの記録です。

境界は、地図の上の線ではなく、地形と補給が決めた妥協点です。この見方は、いまの中東の国境（一橋R8Ⅲ）とも、東大の海洋の問題ともつながります——動かせるものと動かせないものを分ける、という同じ作業です。
