ゴムの木の樹液が、世界を一本につないだ

論述（150字×2を含む）
経済気候・資源交流・移動

問題 まずは自分で解いてみる

問題文問題冊子 6ページ〜7ページ

3　次の文章を読み、以下の設問に答えなさい。

ヨーロッパでは、18世紀末に産業革命が始まると、科学革命に裏打ちされた機械工業が発達し、工業化が進展していった。この結果、国内市場の統合が強化されると共に、国際的にも人の移動や物流、情報の伝達が促進されていった。

例えば、通信手段としてモールスらによって1が実用化されると、国・地域を越えた情報のやり取りは飛躍的に促進されていった。1830年代にはヨーロッパにおいて主要都市間の通信網が整備され、即時的な情報のやりとりが普及していった。

1840年代になると、東南アジアのボルネオ島やマレー半島に自生していたガタパーチャという植物の樹液の特性が注目されるようになった。この樹液は加熱すると柔らかくなり容易に成形することができるが、冷えると形を保持することができた。空気中では酸化されやすいものの水中では変質しにくく、絶縁性も高かった。この性質が注目され、海底電線ケーブルの素材として利用された。1851年にはドーバー海峡に海底ケーブルが敷設され、1856年に最初の大西洋横断海底ケーブルが接続された。その後急速に世界各地へとネットワークが広がっていった。

遠く離れた地域が情報伝達のネットワークに接続されることで、情報のもつ意味合いも変わっていった。各都市の商品相場や金融の情報は即時に他の地域にも伝わるようになり、ニュースを配信する通信社が成長していった。またケーブルの材料となるガタパーチャの栽培、輸入、販売を独占した2は、ケーブルの敷設においても有利な立場に立ち、海外植民地を繋ぐ情報ネットワークは発展していった。

このように情報ネットワークは世界中に拡張されていった。19世紀後半には海底ケーブルは東アジアに到達した。3が欧米諸国からの技術導入や海底ケーブルの陸揚げを拒んだことから、中継地点として日本が選ばれた。①1871年に長崎−上海、長崎−ウラジオストック間のケーブルが接続され、日本は国際的な情報ネットワークの一端に組み込まれ、同時に、経済的にも国際経済のシステムに組み込まれていった。

▶ ここからは本教材の読み
指定語句の使い方（重要）
指定語句は、ヒントではなく答え合わせです。正しい順序は①設問文だけで方向を立てる → ②語句で検算する → ③配置して書く。
語句を先に見て方向を決めると、答案は語句をつなぐだけの平板なものになります。そして本番では——語句を見ないと方向すら思いつかない状態なら、その時点で勝負がついている。だからこの教材では、ヒント1で語句を伏せます。
ただしこの大問には、語句の役割が違う二問が並んでいます。問2(2)の語句は広すぎる設問文の範囲を絞る役、問3(2)の対等は読み違いを正す役。どちらの役割かを見分けるのも力のうち——ヒント2・3でその違いを扱います。
問題の骨
公式が名指しした「歴史総合らしい」が効いています。歴史総合は世界史と日本史を分けずに扱う科目——だからこの大問は、モールスの電信から始まって日清修好条規で終わる。ヨーロッパの技術が、東アジアの条約に着地するのを一本で書かせています。
つまずく所
問3(2)で不平等条約の話をすること。日清修好条規は対等条約です。日本が結んだ初めての近代的な対等条約で、相互に領事裁判権を認め、関税も協定で定めた。指定語句に「対等」が入っているのがその合図。
満点への一手
問3(2)は三つの語句が、そのまま三つの段になります。対等（日清修好条規の性格）→ 朝貢（しかし清は朝貢体制を変えていない）→ 開港（開国・開港を求める日本と、朝鮮をめぐって対立）。「対等な条約を結んだのに対立が深まった」という逆説を書けるかが分かれ目です。
中学生の目で見るなら
問1（電信）と問2(1)（パクス＝ブリタニカ）は中学でも届きます。そしてガタパーチャの話は、そのまま理科です——加熱でやわらかく、冷えて形を保ち、水中で変質せず、絶縁性が高い。素材の性質が、そのまま歴史を動かしたという珍しい例。

ヒント2 ― 語句を伏せて、二つの150字の方向を立てる
問2(2)　設問文は「この時期までのイギリスと植民地との関係性について」。
……正直に言うと、これだけでは範囲が広すぎます。関係性は政治でも軍事でも書ける。
そこで本文に戻る——この大問は産業革命・工業化・国際的な物流の話で始まっている。問2(1)はパクス＝ブリタニカを答えさせている。
→ 経済の関係を書け、と文脈が言っている。骨は①イギリスが出すもの → ②植民地が出すもの → ③その結果、植民地はどうなったか。

問3(2)　設問文は「この条約が日本に与えた影響について」。条約は日清修好条規（1871）。
・「影響」＝結んだ後に何が起きたか。条約の中身だけ書いて終わると設問に答えていない。
→ 骨は①どういう条約だったか → ②相手側の事情 → ③その結果どうなったか。

問2(2)　①工業製品を出す → ②原料を取る → ③植民地の経済がゆがむ
問3(2)　①条約の性格 → ②清側の事情 → ③その後の関係
ヒント3 ― 語句を開くと、二つの違う仕事をしている
問2(2)：語句は「範囲を絞る」役
自由貿易→①（イギリスが確立した体制）／ラテンアメリカ→①②（相手地域の名指し）／プランテーション→③（植民地側で広まった経営）／モノカルチャー経済→③（その帰結）。
→ 立てた三段にきれいに乗りました。語句は「経済の話を書け」という文脈の読みを追認しています。この型の語句は、設問文が広いときに範囲を確定してくれる——東大R8第1問(2)と同じ役です。

問3(2)：語句は「読み違いを正す」役
開港／朝貢／対等——ここで手が止まるはずです。日清修好条規＝不平等条約と思って骨を立てていたら、「対等」が置けない。
→ 置けない語句がある＝方向がずれている合図。実際、日清修好条規は日本が結んだ初めての近代的な対等条約で、相互に領事裁判権を認め、関税も協定で定めました。語句が、間違いを一語で撃ち落としてくれたことになります。

そのうえで三段に置き直す：対等→①条約の性格／朝貢→②清は朝貢体制を変えず朝鮮を独立国として扱っていた／開港→③開国・開港を求める日本との対立。
「対等な条約を結んだのに、かえって対立が深まった」という逆説が、この150字の芯です。

検算の読み方
・置けない語句がある → 方向がずれている合図。骨を組み直す。
・語句が置かれない見出しがある → その論点を自分で補う必要がある（語句は骨の全部を指してはくれない）。

◎ 理系の補助線

ガタパーチャは、19世紀の半導体でした。アカテツ科の木の樹液で、天然ゴムと近い成分ながら性質が違う——常温では硬く、加熱すると成形でき、水中で劣化せず、電気を通さない。この四つがそろって初めて、海底に電線を沈められる。1850年代から1930年代まで、代わりになる素材はありませんでした（ポリエチレンの登場でようやく置き換わる）。

だから帝国は木を伐りに行きました。1本の木から取れる樹液はわずかで、採取のたびに木を切り倒す方式が主流だったため、マレー半島の原生林は急速に失われます。大西洋横断ケーブル1本に、推定で数十万本のガタパーチャの木が費やされた。通信網の地図は、そのまま伐採の地図でした。

そして情報の速さが、経済の性質を変えました。ケーブル以前、ロンドンとニューヨークの価格差は船の日数（2〜3週間）ぶんずれていて、その差が商人の利益でした。1866年に大西洋ケーブルがつながると、価格差は数分で消える。商売は「情報を先に知っている」ことでは儲からなくなり、より遠く、より大量に運ぶほうへ移った——現代の市場の形はここで決まっています。

問3の日本が「中継地点に選ばれた」のも、この経済の中の一手です。清が陸揚げを拒んだから長崎が選ばれた——つまり日本は自ら望んで組み込まれたのではなく、隣国の拒否の結果として組み込まれた。開国とは、こういう他人の選択の余りとして起こることでもある。東大R7の「四帝国の解体」も、一橋の石油も、同じ問いの別の年代です——いまの配置は、誰がいつ何を断ったかの積み重ねでできている。
