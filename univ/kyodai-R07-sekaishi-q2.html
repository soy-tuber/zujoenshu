A　中華人民共和国の首都が置かれる北京は、華北平原の北端、北と西を山地に囲まれた要害に位置している。北側はモンゴル高原に近接し、東北へ山を越えればマンチュリア平原に通じ、古来農耕民や遊牧民を含むさまざまな人間集団が往来した。

秦が薊城（けいじょう）と呼ばれたこの地を征服して以来(1)、今日の北京一帯は長く中国王朝の支配下にあり、その北辺に位置した。隋では、当時開発が進みつつあった江南と華北を結びつけるａが建設され、北は涿郡（たくぐん）にまで達し、江南の物資を東北へ大量に輸送することが可能になった。

唐が成立し、太宗（李世民）がモンゴル高原の遊牧国家(2)を打倒すると、この地に置かれた幽州一帯にも、その遺民を含むさまざまな遊牧民と農耕民が隣接して居住した。8世紀に入り、唐が辺境の防衛体制を再編整備する(3)なかで、幽州に拠点を置き強大な権限を握ったのが、ソグド人(4)の血を引く安禄山だった。安禄山は遊牧民の軍事力を中核とする軍団を率い、幽州で唐に対して反乱を起こす。皇帝が都から逃亡するなど、唐は存亡の危機に陥ったが、辛うじて反乱を鎮圧することができた。しかし、以後の唐は弱体化し(5)、幽州を含めた地方の軍事勢力が半ば自立した状況となる。

10世紀初頭には、モンゴル高原東部の遊牧民集団である契丹（キタイ）が台頭し、新王朝を建国する。契丹は華北の政変に介入し、後晋の建国を助けた見返りに幽州を含む地域を割譲された(6)。複数の都を置いた契丹は、幽州を都の一つとして南京と呼び、農耕地帯の本格的な支配に乗り出した。12世紀にマンチュリアより興った女真が建国した金は、契丹と北宋(7)を滅ぼした後、北京の地に遷都して中都と称した。

13世紀にモンゴル帝国が出現すると、遊牧民の強力な騎馬軍事力(8)を背景に、空前の規模でユーラシアの広域を統合する。チンギス＝カンの孫のｂが皇帝に即位すると、モンゴル帝国の中枢を華北とモンゴル高原にまたがる地に移し、金の中都城の北隣に新しい都城として大都を造営し、国号を元（大元ウルス）と称した。内陸の港を設けて海上航路とも連結した大都は、ユーラシア東西を陸路と海路で結ぶ交易・情報網の結節点となった(9)。

14世紀半ばごろより、ユーラシア規模で気候変動や疫病の流行が起こった(10)。このころ、ユーラシア各地のモンゴル政権は解体局面に入り、元でも天災にともなう飢饉（ききん）や疫病が頻発し、各地で反乱が起こってその支配は動揺する。反乱のなかから頭角を現した朱元璋は明を建国し、明の軍隊が大都を占領して元をモンゴル高原へと駆逐した。江南より興った明も、永楽帝のときに北京に都を遷（うつ）した(11)。明の滅亡後、中華の主となった清も北京を都とし(12)、これが現在の北京に受け継がれることになったのである。

B　19世紀、地中海への南下をはばまれたロシアが中央アジアや東アジアへの進出を強めた結果、中国とロシアはいっそう長い国境を接することとなった。以後、両者は対立の時代と友好の時代をくり返してきた。

ロシアはｃ戦争に乗じて清とアイグン条約・北京条約(13)を結び、ユーラシア大陸東端の領土を拡大した。また新疆のイスラーム教徒の反乱に際して一時イリ地方を占領した(14)。清が日清戦争に敗北した後(15)、ロシアは清から東清鉄道の敷設権を獲得し、またｄ半島の旅順・大連を租借した。ロシアは義和団戦争に際しても東三省（東北地方）を一時占領したため、清の知識人や日本への留学生(16)の間で反ロシア運動が起きた。

しかし、第一次世界大戦中にロシアで革命が起こると、新たに成立したソヴィエト政権は、帝政時代の在華利権を全て返還すると宣言した。実行はされなかったものの、当時の中華民国ではソヴィエト＝ロシア（1922年末よりソ連）に対する好意的な認識が広まった。さらに新文化運動(17)のなかでマルクス主義が紹介され、コミンテルンの指導下に中国共産党が結成された。ソ連の援助を得た中国国民党と中国共産党は広州で国民政府(18)と国民革命軍を組織し、政権奪取を目指して北伐を開始した。しかし、北伐のさなかに中国国民党の蔣介石がクーデターを起こし、中国共産党を排除・弾圧した。蔣介石は北京を占領して全国統一を宣言したが(19)、国民政府とソ連の国交は途絶えた。

1937年に日中戦争が勃発すると、第二次国共合作(20)が成立し、ソ連は国民政府への援助を開始した。しかし1941年に日ソ中立条約が結ばれ、ソ連が満洲国の保全を言明すると、国民政府のソ連に対する不信は高まった(21)。

日本の敗戦後、国共内戦が再開され、中国共産党が勝利した。新たに成立した中華人民共和国(22)はソ連と緊密な外交関係をもった。しかしフルシチョフのｅ批判を契機に中ソの関係は悪化に転じた。1963年には中ソ論争は公然化し(23)、1969年には中ソ国境の各地で武力衝突が発生するに至った。

ゴルバチョフがソ連共産党書記長に就任すると、中ソ関係は改善に向かった。ソ連解体をはさんで1990年代から2000年代にかけて中ロ間の国境画定交渉が行われ、妥結したこともあり、以後現在に至るまで中国とロシアは安定した関係を保っている。

趣旨 何を問う問題か

▶ この問題は何を問うているか
問われている力
一つの場所を定点にして、時代を縦に貫く力。ふつうの通史は王朝ごとに横に切りますが、この大問は北京という一点に立って、その上を通り過ぎた王朝を数えるという視点をとっています。同じ土地の上に、まったく違う人々が次々に都を置いたことが見えます。
Aの主題
冒頭が地理の説明から始まっているのが要点です——「北と西を山地に囲まれた要害」「北側はモンゴル高原に近接し、東北へ山を越えればマンチュリア平原に通じ」。つまり北京は農耕地帯の北端であり、遊牧地帯とマンチュリアへの出入口。だから遊牧民系の王朝（契丹・金・元・清）が、そろってここを都にした。地形が歴史を選んでいます。
Bの主題
こちらも冒頭が地理です——「地中海への南下をはばまれたロシアが中央アジアや東アジアへの進出を強めた結果」。南に出られなかったから東に来た。そして本文は「対立の時代と友好の時代をくり返してきた」と要約している。アイグン・北京条約 → 反ロシア運動 → ソ連との蜜月 → 中ソ対立 → 国境画定という往復が、そのまま設問の順序です。
つまずく所
(22)が条約名を答える問題だと思うこと。問われているのは「下線部がどの国を想定した文言と理解されているか」——(ア)は中ソ友好同盟相互援助条約で「日本と同盟する国」＝アメリカ合衆国、(イ)は米中共同声明（上海コミュニケ）で「覇権を打ち立てようとする他のいかなる国」＝ソ連。同じ中国が、22年で名指しする相手を入れ替えている——それを読み取らせる問題です。
満点への一手
年号の並びを最初に紙に落とす。Bは1858/60 → 1881 → 1895 → 1900 → 1917 → 1921 → 1927 → 1936 → 1937 → 1941 → 1945 → 1950 → 1956 → 1963 → 1969 → 1972 と、ほぼ順番に下線部が並びます。年表を書けば、下線部の位置がそのまま答えの位置になる。
中学生の目で見るなら
北京の名前は何度も変わっています。薊（けい）→ 幽州 → 契丹の南京 → 金の中都 → 元の大都 → 明・清の北京。都市の名前は、その時どこから見ていたかを表します——契丹にとっては「南の京」、元にとっては「大きな都」。名前が視点の記録になっている。

◎ 理系の補助線

なぜ北京だったのか。地図を見ると答えが出ています。北京は華北平原の北の端にあります。ここより北は山地で、越えればモンゴル高原とマンチュリア。つまり北京は農耕地帯と遊牧地帯の境界に立つ門です。

だから、この都市を都にした王朝の顔ぶれが偏っています。契丹（キタイ）、女真（金）、モンゴル（元）、満洲（清）——いずれも北から来た人々です。彼らにとって北京は「農耕地帯を支配しながら、故地への退路も確保できる位置」でした。逆に、江南から興った明が最初の都を南京に置き、永楽帝がわざわざ北京へ遷都したのは、モンゴル対策のために自ら国境に座ったということです。「天子、国門を守る」と呼ばれます。

そして、この位置は弱点でもありました。1449年の土木の変では皇帝が捕虜になり、1644年には清軍が(12)の手引きで山海関を越えて北京に入っています。門の上に都を置けば、門が破られた瞬間に都が落ちる。

Bのほうは、もっと単純な地理から始まります。ロシアが「地中海への南下をはばまれた」——不凍港が欲しかったのに、黒海から地中海へ出る海峡はオスマン帝国が握り、クリミア戦争で英仏に阻まれた。南がだめなら東。ウラジヴォストークという地名は、ロシア語で「東方を支配せよ」という意味です。都市の名前が、国家の意図をそのまま書いている。

ここに、この教材の中で最も長い補助線が引けます。京大R7Ⅰのオスマン帝国が地中海を押さえていたこと → だからロシアは南下できず → 東アジアへ来た → 東清鉄道と旅順 → 日露戦争。ウィーン包囲とウラジヴォストークが、一本の線でつながっている。

最後に(22)について。1950年に中国は「日本と同盟する国」＝アメリカを敵として想定し、1972年には米中で「覇権を求める国」＝ソ連を牽制した。22年で、味方と敵が入れ替わっています。そして条約の文面は、どちらも相手国を名指ししていません——「日本と同盟する国」「他のいかなる国」。外交文書は、名指しを避けることで意味を運ぶ。読む側は、書かれていない名前を補って読んでいます。この読み方ができるかどうかが、(22)の問いそのものです。
